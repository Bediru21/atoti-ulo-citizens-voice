# የአቶቲ ኡሎ ወረዳ — የዜጎች ድምፅ ፖርታል

ይህ የመጀመሪያ የሚሠራ MVP ነው። የቅሬታ መመዝገብ፣ ልዩ የመከታተያ ቁጥር (AU-YYYY-000001 ቅርጽ)፣ የጉዳይ ሁኔታ መከታተል፣ የአስተዳዳሪ መግቢያ፣ ዳሽቦርድ፣ ምደባ/ምላሽ ማዘመን፣ ሪፖርቶች እና CSV ማውረድ ይዟል። የአማርኛ በይነገጽ እና ለስልክ ተስማሚ ንድፍ አለው።

## በኮምፒውተር ላይ ማስኬድ

1. Python 3.10+ ይጫኑ።
2. ይህን ፎልደር ይክፈቱ እና terminal/command prompt ያስነሱ።
3. `python -m venv .venv` ያስኬዱ።
4. እንደ OS ተስማሚውን የvirtual environment ማንቃት ያድርጉ።
5. `pip install -r requirements.txt` ያስኬዱ።
6. ከመጀመሪያ ማስኬድ በፊት `ADMIN_USERNAME` እና `ADMIN_PASSWORD` የenvironment variables ያዘጋጁ። ምሳሌ (Linux/macOS):
   `export ADMIN_USERNAME=admin`
   `export ADMIN_PASSWORD='የራስዎ-ጠንካራ-የይለፍ-ቃል'`
   ከዚያ `python app.py` ያስኬዱ።
7. በbrowser ውስጥ `http://127.0.0.1:5000` ይክፈቱ። አስተዳዳሪው በ `/admin/login` ይገባል።

**አስፈላጊ:** የመጀመሪያ አስተዳዳሪ በመጀመሪያ የዳታቤዝ መፍጠር ጊዜ ብቻ ይፈጠራል። ዳታቤዙ ቀድሞ ከተፈጠረ፣ አዲስ admin ለመፍጠር የዳታቤዙን ቁጥጥር በደህና ያድርጉ ወይም የማስተዳደር ስክሪፕት ያክሉ።

## ለሕዝብ ከማቅረብ በፊት

ይህ ምሳሌ የማስጀመሪያ ኮድ ነው፣ ለproduction በቀጥታ ለመጠቀም አይደለም። HTTPS፣ ጠንካራ የSECRET_KEY፣ CSRF መከላከያ፣ login rate limiting፣ የአስተዳዳሪ ሚናዎች፣ የዳታቤዝ ምትኬ፣ የግላዊነት ፖሊሲ፣ የደህንነት ሙከራና የማስተናገጃ አወቃቀር መጨመር አለባቸው። በአሁኑ ስሪት ማስረጃ ፋይል መጫን አልተካተተም።

የቀበሌ ዝርዝር እና የተቋማት ስሞች ለምሳሌ ናቸው፤ ከአቶቲ ኡሎ ወረዳ እውነተኛ ዝርዝር ጋር መተካት ያስፈልጋል።
